# 轮盘功能夹三级配置界面与属性面板精简重构方案

彻底净化二级属性面板，精简为仅保留“收起/展开”与“进入三级配置”入口；重构三级全屏/弹窗界面中的槽位增加、键位替换与移除机制；建立“三级界面 ⇄ 画布点选按键 ⇄ 自动返回三级界面”的交互闭环，并严格执行“按键被收纳后在主画布隐藏”的显示规则。

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 基于用户最新确认的核心交互与视觉规范：
> 1. **属性面板彻底净化**：坚决不在属性面板上展示槽位列表、按键数量徽章或点选按键，属性面板在选中轮盘/功能夹时，**仅保留主画布收起/展开切换与进入三级界面的按钮入口**。
> 2. **三级界面键位管理**：三级界面作为唯一负责配置槽位的核心阵地，提供清晰的槽位卡片（3~8 槽位限制），支持**点击增加键位**、**点击替换键位**与**点击移除按键**。
> 3. **画布点选与自动返回闭环**：在三级界面中点击“从画布选择按键”后，平滑返回画布进行点选收纳，点选完成后**自动返回三级界面继续确认配置**。
> 4. **被收纳按键隐蔽规则**：被收纳入轮盘/夹内的按键，在主画布折叠态下完全隐藏，不占用画布独立位置。

- **Confirmed Decision 1**: 属性面板只保留折叠/展开与三级界面跳转按钮。
- **Confirmed Decision 2**: 三级界面支持增加槽位、替换键位、移除键位、去重防呆与最少 3 个/最多 8 个限制。
- **Confirmed Decision 3**: 画布点选完成后自动重新打开并返回三级界面。

## 1. Overview & Core Concept

### What It Does
- **属性面板极致精简**：当用户在画布选中轮盘功能夹（Wheel Folder）或抽屉功能夹（List Folder）时，顶部属性面板恢复整洁，仅提供基础调整以及 `[ 展开 / 收起 ]` 与 `[ 配置轮盘按键 / 三级界面 ]` 两大核心操作。
- **专业三级配置界面（Tier-3 Folder Configurator）**：
  - 以现代化游戏手柄/串流客户端标准呈现轮盘与槽位。
  - 用户可在此直观查看当前槽位列表（Slot #1 ~ Slot #8）。
  - **增加键位**：若当前未满 8 槽，点击 `[+ 增加槽位]` 扩展轮盘。
  - **替换键位**：点击任意槽位的 `[替换按键]`，支持直接弹出画布候选按键，或点击 `[从画布点选]` 进入画布直接点选。
  - **移除按键**：点击移除将按键释放回画布；若槽位多于 3 个，可缩减插槽。
- **“三级 ⇄ 画布”往返闭环**：
  - 点击“从画布点选”后暂隐三级弹窗，画布高亮呈现可收纳按键。
  - 用户点击画布元素完成点选后，点击顶部浮条 `[完成并返回三级界面]`，弹窗平滑再现并刷新配置。

### Visual & Layout Polish
- **属性面板**：不再塞入密集的小芯片与数量标签，保持与常规单键属性同等高度与极简审美。
- **三级界面槽位卡片**：
  - 采用深色磨砂质感卡片（`bg-[#181822] border border-white/10 rounded-2xl p-3`）。
  - 每个槽位标明 `#1`、`#2`、绑定的按键标签、原按键名、及操作动作（替换、移除、清空）。
- **动效与反馈**：
  - 从三级界面切入画布点选时，三级界面淡出，画布浮条滑入；
  - 点选完毕后，三级界面带有丝滑聚焦动效重新唤起，对应槽位高亮闪烁提示刚刚绑定成功。

## 3. Key Product Decisions & Trade-Offs

### Decision 1: 属性面板与三级界面的职责切分
- **切分原则**：属性面板只负责“画布级形态控制（展开/收起）”与“进入深度的三级入口”；所有与具体插槽、按键映射、替换、删除相关的复杂操作全部收敛在三级界面内部完成。
- **优势**：避免属性面板因塞入 8 个插槽而横向溢出或纵向变厚，阻挡画布视野；符合主流主机手柄与专业移动外设设计惯例。

### Decision 2: 键位替换与添加的交互路径
- 用户在三级界面的某个槽位上点击“替换按键”时：
  - **弹层快速选择**：在弹窗内直接列出当前画布上尚未被收纳的按键列表（带按键标签与名称），点击一键替换。
  - **画布直接点选**：提供“返回画布点选”按钮，用户可以直接面对真实游戏串流画面布局点选需要的按键。

### Decision 3: 被收纳按键的画布可见性
- **严格规则**：当一个按键的 `folderId` 等于当前轮盘 ID 时：
  - 在主画布处于**收起状态（折叠）**时，该按键不在主画布上独立绘制，保持画布干净；
  - 只有当轮盘处于**展开状态**或在**三级界面点选编辑**时，才展示其从属按键。

## 4. Technical Implementation Steps

1. **改造 `PropertyPanel.tsx`**：
   - 清理所有在 `PropertyPanel` 中的槽位展示代码（包括横屏的槽位 chips、竖屏的槽位 grid、数量徽章等）。
   - 保留且优化：
     - `[ 收起 (折叠) ] [ 展开 (呈现) ]` 切换开关；
     - `[ ⚙️ 配置轮盘槽位 (三级界面) ]` 按钮。
2. **重构 `FolderTier3Editor.tsx`**：
   - 打造结构清晰的槽位管理面板：
     - 槽位列表（3~8 槽位限制，支持删除、增加、替换）。
     - 支持在槽位上直接点击“替换”唤起“画布候选按键快捷选择器”。
     - 增加 `[ 👆 从画布直接点选收纳 ]` 按钮。
3. **闭环链路联动（`App.tsx`）**：
   - 当用户在三级界面点击“从画布直接点选”时：
     - 暂存当前三级界面编辑状态。
     - 关闭三级界面弹窗，进入画布点选模式。
     - 顶部显示“完成点选并返回三级界面”浮动条。
     - 用户点选完毕后，自动执行 `setIsWheelModalOpen(true)`，返回三级界面继续确认与保存。
4. **编译与验证**：
   - 执行 `compile_applet` 和 `lint_applet` 确保 TypeScript 类型与交互零错误。
